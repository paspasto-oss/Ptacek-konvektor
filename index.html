1. Načítanie zdrojového dokladu

Presuňte sem XML výdajku od Ptáčka alebo Excel prílohu ponukyPodporované súbory: XML, XLSX. Súbor sa spracuje iba vo vašom prehliadači.
Nahrajte XML výdajku od Ptáčka alebo Excel prílohu ponuky z POHODY.

2. Nastavenie objednávky POHODA

Musí byť IČO firmy otvorenej v POHODE.
Vyplňte len pri rovnakých kódoch vo viacerých skladoch.
Musí presne existovať v zozname foriem úhrad.

4. Vytvorenie XML pre POHODU

Postup v POHODE

1. ImportSúbor → Dátová komunikácia → XML import/export a vyberte vytvorený XML.
2. KontrolaV agende Vydané objednávky overte dodávateľa, skladové kódy, množstvá a ceny.
3. PríjemkaV agende Príjemky použite Záznam/Prenos → Vydané objednávky.
4. Výsledok importuNajčastejší problém je neexistujúci skladový kód.

Excel príloha: aplikácia číta označenie dodávky z riadku, množstvo zo stĺpca H, MJ zo stĺpca J, jednotkovú cenu zo stĺpca K a DPH zo stĺpca R. Riadky bez skladového kódu sa neimportujú.
